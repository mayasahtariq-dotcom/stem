# M1 demo: login, roles and classrooms

Debug builds use a **test login and test data**, so this works with no internet or accounts. Install the debug APK from the latest **Android** run in GitHub Actions (Artifacts → `app-debug`).

## 1. Sign up as a teacher and create a class
1. Open **Mooshala** and tap **चलो शुरू करें / Let's start**.
2. Enter any 10-digit mobile number starting with 6–9, then tap **Send OTP**.
3. Type **123456**. The screen shows "Test login: use code 123456" as a reminder. It moves on by itself once all 6 digits are in.
4. Pick **हिंदी** or **ಕನ್ನಡ**. The app switches language immediately.
5. Pick **Teacher**, type your name and tap **Let's go!** You land on the teacher home.
6. Tap **Create classroom**. Enter a name, pick a subject and grade, and leave both languages ticked. Tap **Create**.
7. The key screen shows the key (for example BI09-K4X2) in a cream box, with a QR code below it.
   - **Copy** copies the key.
   - **Share** opens the share sheet with the class name, key and link, so you can choose WhatsApp.
   - **Students (0)** opens the class details and member list.

## 2. Switch to a student and join
1. Open **Profile**, the teacher icon at the top right. Under **Your roles**, tap **Add a role** next to **Student**. You're now on the student home.
2. Tap **Join a class**. Type **BI09-K4X2**, the demo class. The boxes capitalise letters, move to the next box by themselves and add the dash.
3. A preview appears: Class 9-A Science · Mrs. Rao · Biology · Class 9 · 38 students. Tap **Join**. The class now shows under **My classes**.
4. Or tap **Scan QR code** and point the camera at a teacher's QR code.

## 3. See each join error (bilingual)
| Type this key | Message |
|---|---|
| `BI09-ZZZZ` (any unknown key) | No class has this key |
| `BI09-XPRD` | This class key has expired |
| `CH10-KNDA` (in Hindi mode) | This class doesn't use your language |
| `BI09-K4X2` again after joining | You're already in this class |
| any 11 tries within an hour | Too many tries |

## 4. Links and returning users
- With the app installed, open `stemtutor://join/BI09-K4X2`, for example from a note or a test link. The join screen opens with the key filled in.
- Close the app and reopen it. It goes straight to the home of the role you last used.
- In **Profile** you can switch language, switch role, add a role, or sign out. Debug builds also have a **Component gallery** button.
- The **Parent** role opens a placeholder, where the cow says linking a child is coming soon.

## Real login with Supabase (still to verify on a device)
1. In `backend/.env`, set `DATABASE_URL` to the Supabase Postgres connection string, from Project Settings → Database. Then run `alembic upgrade head` from `backend/`.
2. Run the backend on the PC with `uvicorn app.main:app --host 0.0.0.0 --port 8000`. The phone must be on the same Wi-Fi.
3. In `app/local.properties`, set `USE_REAL_API=true` and `API_BASE_URL=http://<PC's Wi-Fi IP>:8000/`. Then rebuild.
4. Sign in with the Supabase **test phone number**, using its test code `123456`. Sending real SMS needs Twilio and DLT registration.

## Backend tests
`cd backend && .venv/Scripts/pytest` runs 42 tests against an embedded Postgres. They include:
- a student can't see another class's members (both the endpoint and RLS);
- teachers see only their own classes;
- the 11th attempt is refused;
- every join error code;
- 10,000 keys are unique and never use 0, O, 1, I or L.
