# M0 demo: Foundation

## App: component gallery

1. Install the debug APK: download `app-debug` from the latest **Android** run in GitHub Actions, or build it with `cd app && ./gradlew installDebug` (needs Android Studio / the SDK).
2. Open **STEM Tutor**. It opens on the component gallery in **Hindi mode** (the default), whatever the phone's language is.
3. Scroll through: bilingual text in small, medium and large sizes; chunky buttons (blue, cream, neutral, disabled; press and hold one to see it sink); answer options (tap one to select it) and every option state; the streak/XP/hearts bar; the source chip; and the loading, error and empty screens.
4. At the top, tap **ಕನ್ನಡ + English**. Every regional line switches to Kannada straight away, with no app restart, and the English lines stay the same. Tap **हिन्दी + English** to switch back.
5. Close the app fully and reopen it: it stays in the language you last chose.
6. The **Backend status** section at the bottom shows "Connected (version fake)", because debug builds use the fake backend. To use the real one, set `USE_REAL_API=true` and `API_BASE_URL` in `app/local.properties` and run the backend.

Android Studio previews: open any file in `core/designsystem/.../component/` or `GalleryScreen.kt` and each preview renders in Hindi and in Kannada.

## Backend

```
cd backend
cp .env.example .env            # set SUPABASE_JWT_SECRET (Supabase → Project Settings → API → JWT secret)
docker compose up --build       # Postgres + API; runs migrations at start
curl localhost:8000/health      # {"status":"ok","version":"0.1.0"}
curl -i localhost:8000/me       # 401
curl -H "Authorization: Bearer <a Supabase access token>" localhost:8000/me   # {"id":"<user id>"}
```

Without Docker: `.venv/Scripts/uvicorn app.main:app --reload` (on Linux/macOS, `.venv/bin/` instead of `.venv/Scripts/`). `/health` and `/me` work without a database.

## CI

Each push runs the **Android** workflow (lint, unit tests including the Robolectric BilingualText UI test, debug build) and the **Backend** workflow (ruff, mypy, pytest including the migration + RLS test on Postgres).
