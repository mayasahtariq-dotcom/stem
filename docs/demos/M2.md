# M2 demo: notes to course

Debug builds use a **fake AI**, so this works offline: any notes produce a sample Class 9 Biology course on the cell. Install the debug APK from the latest **Android** run in GitHub Actions.

## Teacher: photograph notes, then review and publish
1. Sign in with the test login (any number, code 123456) as a **Teacher**, and create a classroom if you don't have one.
2. On the teacher home, tap the cream **Make a course from notes** button.
3. Add pages:
   - **Camera:** take several shots in a row, then tap **Done**.
   - **Gallery** or **PDF:** a PDF over 10 MB is refused.
   - **Type notes:** type or paste text, then tap **Add page**.
4. Arrange the pages in the thumbnail strip:
   - Long-press and drag a thumbnail sideways to reorder it, or use the ‹ › buttons.
   - Tap a photo to rotate or crop it.
   - Tap the bin to delete a page.
   - A blurry photo asks **Retake** or **Keep**.
5. Check the subject and grade, choose **For my class** and the class, then tap **Make course**.
6. The generating screen ticks off each step: notes read, organised, topics found, key terms found, lesson 1 being made. You can tap **Leave for now**; a banner appears at the top when the course is ready.
7. Tap **Review the course** to see:
   - the course title (tap **Edit title** to change it in all three languages);
   - the lessons, with question counts and status;
   - lesson 1 showing "1 to check".
8. Open lesson 1. The flagged question is first, with a yellow banner ("Handwriting on page 2 is unclear…"). Each question has three buttons:
   - **Edit:** change the question in हिंदी, ಕನ್ನಡ and English, and pick the correct answer.
   - **Redo:** have the AI write a new version.
   - **Delete:** remove the question.
9. Go back to the course. Opening lesson 1 has made lesson 2: lessons are made only as needed.
10. In lesson 1, tap **Publish**, choosing the class if you have several. In the course, **Assign to classes** lets you pick classes and an optional due date.

## Student: a personal "AI-made" course
1. Switch to (or add) the **Student** role in Profile.
2. On the home screen, tap **Make a course from notes**. It's always "just for me".
3. When it's ready, the course shows under **My courses** with the **AI-made** badge. Playing lessons comes in M3.

## Real AI (to do with your notes)
1. Install the models: `cd backend && .venv/Scripts/pip install -e ".[ml]"`. This is a large download, because of PyTorch.
2. In `backend/.env`:
   - set `USE_FAKE_AI=false`;
   - set `LLM_API_KEY=` to a key for any OpenAI-compatible host, for example a free OpenRouter account;
   - optionally change `LLM_OUTLINE_MODEL`, `LLM_TERMS_MODEL` and `LLM_QUESTIONS_MODEL`.
3. Put 3 photos of real handwritten notes (Hindi, Kannada and English) in `samples/`, then run `python scripts/bakeoff.py ../samples qwen/qwen-2.5-72b-instruct google/gemma-3-27b-it`. The results go to `docs/demos/M2-samples/`; compare them and pick a model.
4. Run the backend with the real AI, set `USE_REAL_API=true` in the app, and time "photos → outline + lesson 1". The PRD target is under 60 seconds.

## Tests
- **Backend (59 tests):**
  - the pipeline with fake AI, with statuses in order;
  - invalid JSON gets one retry, then is marked as needing review;
  - lesson 2 waits until lesson 1 is opened, then is made exactly once;
  - a student gets 403 on an unpublished lesson (endpoint and RLS);
  - invented page numbers are corrected;
  - edit, redo, delete, assign and personal courses.
- **App:**
  - reordering, deleting, the 10-page limit, the PDF size limit and the blur prompt;
  - compression size, the blur score and crop maths;
  - generating steps arrive in order;
  - flagged questions come first;
  - the question JSON round trip.
