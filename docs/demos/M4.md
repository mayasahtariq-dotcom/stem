# M4 demo: teacher dashboard, parents, consent and the Student Twin

## Offline (pretend mode)

- **Teacher:** open a class → **Class dashboard**. See the three tiles, weak topics (red/amber/green bars, "N students still find this hard"), and the students list with behind and idle students first, in red. Tap Chetan: lessons, accuracy, "What they find hard" (from the twin) and "Often mixes up Mitochondria and Nucleus". Flip **School has collected consent**.
- **Student:** Profile → **Link a parent**: a 6-letter code and QR, and the linked parents (remove one). Term cards show "You know this: N%" once practised (real server).
- **Parent:** sign in with the Parent role. Home shows Ananya's dashboard: this week ▲, accuracy "Improving", strongest/weakest topic, assignments (one overdue in red), classes, and **Listen to summary**. Tap the Ravi chip: the empty state and "waiting for approval" → **Review and approve** → **I approve**. Tap **+** and enter `KAV234` to link Kavya. **Child settings:** withdraw consent, remove link, delete data (each asks first).

## Real (PC dev server)

1. Three Supabase test numbers: a teacher, a student and a parent.
2. Teacher: make and publish a lesson to a class. Student: join the class.
3. Student: start the lesson → "a parent needs to approve" → **Link a parent**.
4. Parent: **Add child** → enter or scan the code → Link → **I approve**.
5. Student: play the lesson. Teacher: the dashboard and student detail fill in (refresh after up to 5 minutes, the cache). Parent: the dashboard and **Listen to summary** (Sarvam).
6. Parent: withdraw consent → the student's next lesson is blocked again.
